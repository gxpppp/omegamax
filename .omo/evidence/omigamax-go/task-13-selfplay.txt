1. GENERATOR DESIGN  (omigamax/train/selfplay.py)
--------------------------------------------------------------------------
play_game(network, cfg, ...) -- one full self-play game, the same network on
both colours:

  * Opening: empty board (Board(size)); terminal: two consecutive passes
    (Board.is_terminal); scoring: Tromp-Taylor area + komi 7.5 -> winner
    "B"/"W" (jigo impossible with komi 7.5).
  * Per move: fresh search root (mcts.new_root), run_search(simulations)
    with the config's batched leaf evaluator (BatchedNetworkEvaluator,
    leaf_batch 16); AGZ Dirichlet root noise (alpha 0.03 / eps 0.25) is
    re-sampled on every move's fresh root (todo-10 machinery, seeded rng).
  * Temperature schedule (caller-side tau switching, plan todo 10):
    tau = 1.0 for the first temperature_threshold (30) moves ->
    sample_action(tau=1) proportional to visit counts; afterwards
    tau = 0.0 -> sample_action(tau=0) = argmax (ties uniform-random).
  * Training tuple recorded per move, BEFORE the move is applied:
      s  = encode(up to 8 prior game positions, mover colour)  -> (17,N,N) f32
      pi = temperature_policy(root, tau)  (search distribution, NOT a one-hot)
      z  = z_targets(move_count, winner): +1 if the mover won, -1 otherwise.
  * Resign: config resign_threshold = 0.0 disables it (the AGZ 0.5% resign is
    a documented extension behind the same config bit, only active when > 0);
    the branch is implemented and unit-tested with a constant-value probe net.
  * Timeout protection: > max_moves (1000) force-terminates, scores the
    position and marks forced_terminal.
  * Inference discipline (plan G3): network.eval() before the game; every
    forward runs under torch.no_grad() (BatchedNetworkEvaluator) -> BN
    running stats are never updated by self-play; verified by a probe net.

Data storage (generate_games / CLI):
  * One npz per game: data/selfplay/game_<seed:010d>.npz
    (np.savez_compressed, arrays s/pi/z + metadata board_size, komi, winner,
    result, move_count, simulations, temperature_threshold,
    forced_terminal, seed); atomic tmp + os.replace.
  * Pruning: keeps the newest replay_buffer_games (=1000) games, oldest by
    mtime_ns removed.
  * Throughput report: sims/s (total search simulations / single-process
    wall-clock s, network forward included), positions/s, games/hour; the
    plan's soft gate sims/s < 150 -> WARN + optimisation notes (never a
    hard failure; exit code always 0).
  * Cross-move search-tree reuse is a documented extension (plan G4), not
    implemented (fresh root per move).
