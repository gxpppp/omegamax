Date: 2026-08-10 | HEAD base: ab930d6 | Environment: Windows 10, PowerShell 5.1, uv

目标
----
为运行中的 RL 训练循环提供只读的本地 Web 监控面板：训练指标（step/loss/lr/elo/games/cycle + 历史曲线）

面板为独立进程，只读 logs/train.jsonl 与 data/selfplay/*.npz，绝不触碰训练进程/训练文件。

API 规格
--------
GET /                 —— 面板首页（static/index.html）
GET /api/train        —— {latest(step/loss/lr/elo/games/cycle/winrate/replaced),
                           steps[step,loss,lr,games,cycle,timestamp](全部 train_step),
                           evals[step,cycle,winrate,replaced,elo,timestamp],
                           cycles[cycle,step,games,timestamp],
                           events, file_mtime, alive(最近写入<600s), now}
GET /api/games        —— {games: 按 mtime 新→旧、cap 50 的 [{id,name,mtime,size,move_count,
                           winner,result,board_size,komi,forced_terminal}]}
GET /api/games/<id>   —— {id, board_size, komi, winner, result, move_count, forced_terminal,
                           positions[每手后 0/1/2 绝对盘面, 末位=终局盘],
                           moves[{color,r,c,captured} 或 {color,pass,captured}], final}
所有 API 轻量、可高频轮询；缺失/损坏文件返回空列表或 404，绝不 500。

回放推导方法（已在真实 npz 上验证）
-----------------------------------
s 为 17 平面 AGZ 特征：plane 2t=当前方子, 2t+1=对手方子, plane 16=行棋方颜色。
1) 绝对盘面：对每个记录位置 t，按 plane16 判定行棋方，平面 0 映射为行棋方棋子(1/2)、平面 1 映射为对方棋子，
   得到 0/1/2 棋盘（loop.py `_reconstruct_board_state` 同布局；本面板独立实现、不导入训练循环）。
2) 中间手（t<T-1）：第 t 手 = 相邻两盘面间“唯一新增子的交叉点”，无新增子=停一手。
   —— 与规则引擎 Board 逐盘面 FULL-GRID 全等验证通过（6 局真实棋局，含 459/596 手长棋）。
3) 最后一手：双停自然终局 → 最后一手=停（记录末位盘面即终局盘，按 stored result 计分精确复现）；
   max_moves 强制终局 → 末手 = pi[T-1].argmax()（temperature_threshold 后 tau=0，采样即 argmax），
   按 stored result 计分精确复现（8 局全部 match）。
结论：平面差分法精确；pi-argmax 不可靠（温度 1 时非 argmax 采样，实测 game_0100 第 97 手不一致），仅用于强制终局末手。

前端功能
--------
- 指标卡：step / loss / lr / ELO / games / cycle（最新值实时刷新）
- Canvas 曲线：loss、elo、lr 三条（无外部图表库；loss 降采样至 ~600 点）
- 棋局缩略图网格（最新 ~6 局，Canvas 木纹棋盘 + 最终局面 + 胜方/手数/结果）
- 点击棋局 → 全尺寸棋盘回放：上一手/下一手/首末/自动播放/滑块拖动/键盘(←/→/空格/Esc)
- 每 2.5s 轮询 /api/train + /api/games，只重渲染变化的棋局，不重置用户已打开的棋局/播放位置
- 顶部“训练运行中/已停止”状态灯 + 最后更新时刻（liveness=最近写入文件 <600s）
- favicon 204 兜底；Chrome/Edge 实测无 console 错误
