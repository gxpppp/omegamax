ARCHITECTURE (Oracle-adjudicated pre-commitment, honoured)
---------------------------------------------------------
- The C++ tree owns nodes/boards exclusively; NO Python mirror, NO
  bidirectional sync during the search.
- When a leaf is submitted to the batched evaluator, a TRANSIENT Python
  Node shell is built (board snapshot + threaded color + legal_moves +
  parent chain + full Node attribute set). After the flush the C++
  engine discards the shell and backprops into its own C++ nodes.
- Identity matching: the shell submitted IS the object the evaluator
  returns (submission-order list; each flush verifies `fnode is shell`,
  mcts.py:536-541 protocol). One bug found & fixed during bring-up: the
  shell cache used `!is_none()` to test for a built shell, but a
  default-constructed (null) py::object reports `is_none() == False` --
  unbuilt slots were mistaken for cached shells and a null object was
  submitted. Fixed to `ptr() != nullptr`.

C++ ENGINE (cpp/mcts_engine.h/.cpp)
-----------------------------------
- Node pool: int indices, parent/children{action,node} ascending/prior/
  visit_count/value_sum(double)/virtual_loss/noisy(via root map)/color/
  legal_moves(lazy). Boards in a separate pool (deep copy per child).
- UCB selection: double, SAME operation order as Python select_child
  `q + c_puct * prior * sqrt(N_parent) / (1 + N_eff)`, tie-break LOWEST
  action index (children iterated ascending; strictly-greater compare).
  std::sqrt == math.sqrt (correctly rounded SSE2) => bit-exact.
- Expand: deep-copy board per legal child, play(pass/point,
  check_legal=false) -- mirrors mcts.py:328-352; child color = 3 - parent.
- Backprop: negate value at every level, value_sum += v in double.
- Search loop mirrors run_search's batched path exactly (terminal leaves
  never evaluated; re-selecting a pending leaf flushes; virtual-loss
  claim/release in try/finally; tail batch flushed).
- import(): rebuilds the C++ tree from the caller's Python root (board
  state/pass_count/last_captured/moves-count, threaded color, stats,
  existing subtree). export(): materializes the C++ tree back onto the
  root (stats + children dict, ascending insertion order).
- Root noise: Dirichlet is applied by Python BEFORE routing; C++ receives
  the {action: noisy} map and uses it only at the root. Root children are
  exposed in ascending action order so a Python-side eta vector maps
  bit-identically.
