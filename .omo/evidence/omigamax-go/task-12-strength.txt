PROTOCOL (plan todo 12, authoritative)
-------------------------------------
- Harness: omigamax/cli/mcts_strength.py (new). Reuses existing MCTS search
  (omigamax.mcts.run_search + BatchedNetworkEvaluator, todos 9-11) and the
  rules engine (Board / two-pass terminal / Tromp-Taylor scoring, komi 7.5,
  todos 3-4). No search/rules code reimplemented.
- Ladder: 40 / 200 / 800 simulations per move; the three levels play pairwise
  (40v200, 200v800, 40v800), >=60 games per pairing in the full protocol,
  same fixed network, same komi, alternating colours (higher-sim side plays
  black in exactly half the games).
- Move selection: MCTS agent samples the visit-count policy at tau=1.0
  (AGZ temperature selection, todo 10); random baseline opponent plays
  uniform-random legal moves + pass.
- Fixed weight: random init (torch seed 0) -- the plan's default.
- Acceptance: P(800>200) > 0.5 AND P(200>40) > 0.5 in the win-rate matrix;
  harness exits 0 iff accepted (else 1).

CONCLUSION
----------
- Directional monotonic signal holds on the plan's smoke-trained fallback

  default shows no signal (P(200>40)=0.500), as the plan explicitly warned.

  genuinely trained network exists (todos 13-16); the plan's acceptance
