Design
------
All modes load the net via train.load_checkpoint with the ARCH READ FROM THE
CHECKPOINT (models/pretrain.pt restores b20c256 regardless of config), put the
net in eval() mode, and run inference under torch.no_grad -- nothing trains.

1. human-match -- SL accuracy on a held-out eval set.
   Eval set: sampled ON THE FLY from data/pretrain/chunk_*.npz (13 chunks,
   5,122,072 samples) with the fixed eval seed 0x5EED (24237), deliberately
   distinct from the P5 training seeds (0/..). Reuses the exact PretrainChunks
   memory-mapped loader + uniform sample_batch from omigamax/train/pretrain.py
   WITHOUT training -- just iterate. No files written under data/pretrain.
   Reports top-1 (argmax == human move), top-5, policy CE, value MSE and the
   Pearson correlation between z and tanh(value) -- plus the SAME metrics for
   a uniform-policy RANDOM baseline (the "untrained floor": empirical top-1
   ~1/362, top-5 ~5/362, exact CE = ln(362), MSE = mean(z^2), corr 0).
   CPU-safe default: --samples 20000.

2. bench -- N MCTS games checkpoint vs baseline (or --opponent checkpoint).
   Reuses omigamax/train/evaluate.play_eval_game (the todo-15 gate engine:
   no Dirichlet root noise, tau=0 argmax, batched no_grad inference). The
   self-play generate_games path plays ONE net on both sides, so a two-net
   match must go through play_eval_game. Default opponent: a random-init
   create_model(blocks, channels, board) of the checkpoint's own arch = the
   "before training" baseline. Colours alternate (checkpoint black on even
   games, white on odd; komi 7.5 favours white). Default N=10, sims=150
   (plan: 100-200, CPU-feasible). Reports win rate each side, draws, avg
   game length.

3. report -- combined human-readable summary of both modes' JSON evidence
   into .omo/evidence/omigamax-go/task-P8-eval.txt (--report overrides).

CLI (mirrors pretrain.py's argparse style; config/default.yaml read, never
modified):
    uv run python -m omigamax.cli.evaluate human-match \
        --checkpoint models/pretrain.pt --samples 20000
    uv run python -m omigamax.cli.evaluate bench \
        --checkpoint models/pretrain.pt --games 10 --sims 150
    uv run python -m omigamax.cli.evaluate report
Checkpoint default: models/latest.pt (latest_checkpoint_path()).

Tests (tests/test_evaluate.py -- appended under TestP8HumanMatch /
TestP8Bench / TestP8Report; CPU-only):
  (a) test_tiny_run_metrics_sane_and_deterministic -- 9x9 net (blocks 1,
      channels 8) + tiny synthetic chunk corpus (2x40); run_human_match twice
      under one seed -> identical metrics, top-1/top-5 in [0,1], CE/MSE/Pearson
      finite, arch round-trips.
  (b) test_random_baseline_19x19_top1_about_1_over_362 -- on the real 19x19
      geometry (D=362): top-1 ~ 1/362 within 0.01, top-5 ~ 5/362 within 0.02,
      CE = ln(362), value MSE = 1 (z in +-1).
  (c) test_tiny_bench_end_to_end_winrate_dict -- bench with tiny config
      (9x9, blocks 1, channels 8, 50 sims, 2 games, random-init baseline)
      runs end-to-end and returns a win-rate dict with consistent
      a_wins+b_wins+draws == games, per-game records sane.
  (d) test_report_writer_creates_file -- write_report creates the file with
      both modes' numbers.
