## 3. Key algorithm notes (each maps 1:1 to the Python reference)

  play/pass  board.py:124-157  -- check_legal first; pass -> pass_count++,
             last_captured=None; stone -> pass_count=0, place, capture,
             last_captured = the point iff removed==1 (single-stone group is
             unambiguous) else None; move_count++.
  is_legal   legality.py + ko.py:14-28 -- order: on-board, empty, fast-path
             empty-neighbor (keeps a liberty), else placement simulation on a
             COPY + has_capturable_group() || has_liberty(); then simple-ko
             retake check vs last_captured_.
  capture    captures.py -- for each adjacent opponent group with no liberty
             (early-exit has_liberty), collect full group (DFS), remove.
  has_liberty liberties.py:75-99 -- group DFS with early exit at first empty
             neighbor; empty point -> False.
  territory  scoring.py:27-61 -- flood-fill empty regions; owner = the single
             bordering color, else neutral; empty board -> every point None.
  score      scoring.py:64-84 -- stones + territory + neutral/2, komi on
             white, same left-to-right float evaluation order.
  result_string: f"{x:g}" reproduced for the only reachable margins
             (non-negative integers and half-integers) via fmt_margin().
  legal_actions mcts.py:227-248 -- row-major point indices then pass
             index size*size; color None -> derive from move-count parity
             (black opens, even count).

  No numpy/torch in C++; the binding layer (omigamax_core.cpp) contains no
  rules logic. C++17 (MSVC 19.44), pybind11 3.1.0.
