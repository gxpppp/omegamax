IMPLEMENTED ALGORITHMS (exact formulas)
---------------------------------------
1. Dirichlet root noise (omigamax/mcts/mcts.py::apply_dirichlet_noise)
     P'(a) = (1 - eps) * P(a) + eps * eta(a),   eta ~ Dir(alpha)
     alpha = dirichlet_alpha = 0.03, eps = dirichlet_eps = 0.25 (config).
   - Applied ONLY to the root's legal children (root.children == exactly the
     legal moves incl. pass), sampled ONCE per position before the
     simulations (AGZ re-samples per move).
   - Stored in the transient override `root.noisy_prior` ({action: prior});
     `child.prior` network values are NEVER mutated, so repeated search or a
     later run cannot compound stale noise (run_search without noise clears
     the override first). Non-root selection always uses the true priors.
   - Reproducible with a seeded `np.random.default_rng(seed)`.
   - select_child picks `prior = noisy_prior.get(action, child.prior)`.

2. Temperature selection (temperature_policy / sample_action)
     pi(a) propto N(root, a) ** (1 / tau)  over the root's children.
   - tau = 1.0 for the first temperature_threshold = 30 moves (== exact
     visit-count policy, verified), then tau -> 0 (argmax).
   - tau < 1e-6 (TAU_ARGMAX_THRESHOLD) short-circuits to the argmax branch:
     all mass on the most-visited children; ties share the mass uniformly
     (random tie-break, reproducible with a seeded rng). Division by
     tau is impossible in that branch -> no division-by-zero / overflow.
   - Computed in log space ((1/tau)*log N shifted by the max) so tiny
     temperatures never overflow N**(1/tau).

3. Virtual loss (select_child denominator + run_search claim/release)
     UCB = Q + c_puct * P * sqrt(N_parent) / (1 + N_child + virtual_loss)
   - During leaf evaluation run_search claims the leaf
     (node.virtual_loss += 3) inside try/finally and releases it right after
     (`-= 3`), so the effective visit count in UCB is N_child + virtual_loss
     while the leaf is "in evaluation", and the final visit counts / policy
     are exact. This is the seam todo 11's batched leaf evaluation slots into.
