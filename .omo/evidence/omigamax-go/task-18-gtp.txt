IMPLEMENTED (omigamax/gtp/gtp.py + omigamax/cli/gtp_main.py + tests/test_gtp.py)

Command set (GTP v2, per plan todo 18):
  protocol_version / name / version / known_command / list_commands / quit
  boardsize / clear_board / komi / play / genmove
  fixed_handicap / place_free_handicap / set_free_handicap
  loadsgf / kgs-time_settings / time_left / final_score / printsgf
  (kgs-chat handled silently -> empty response; unknown commands -> "? unknown command")

Response format (GTP v2 spec):
  "=id <text>" on success / "?id <text>" on error, id echoed only when the
  client supplied one; blank line terminates every frame; multi-line responses
  (list_commands) continue on bare lines.

Coordinate conversion:
  GTP columns A-T skipping I, rows 1..N (row 1 = bottom; rules engine uses
  0-based (row, col) with row 0 = top). A1=(18,0), T19=(0,18). pass = "pass".

Move generation (genmove):
  Existing MCTS (run_search + BatchedNetworkEvaluator), evaluation discipline:
  NO Dirichlet root noise, tau=0 (argmax) -- deterministic GTP play. Legality
  fallback keeps the sampled action legal for the requested colour (handicap
  parity). Terminal board -> genmove returns "pass".

Time control stubs (per plan: simplified budget-mapping stub; full byo-yomi
clock deferred):
  kgs-time_settings <main> <byo> <stones> (3-arg GNU Go/KGS form) parsed and
  mapped to a search budget: per_move = main/250, sims = clamp(per_move*100,
  8..800); 0-main falls back to byo/stone. KataGo's 4-arg clock-type variant
  (byoyomi/absolute/none/canadian prefix) also accepted for interop.
  time_left <color> <time> <stones>: accepted + stored, no budget change (stub).

Windows pipe handling (gtp_main.py):
  stdout reconfigured newline="\n" + line_buffering (LF-only output, no CRLF
  translation); stdin universal-newlines + rstrip("\r\n") (CRLF tolerated);
  explicit flush after every response frame; python -u documented as optional.

Handicap: fixed/place/set_free_handicap use the standard star-point pattern
  (19/13/9 sizes); after handicap WHITE always moves first (engine tracks the
  count). final_score errors "? game not finished" until two consecutive passes.
