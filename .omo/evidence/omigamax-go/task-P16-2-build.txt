说明: 安装的 scikit-build-core 为 1.0.3，0.x 的 wheel.py-modules 键已移除；
1.x 用 wheel.packages（可指向单个 .py 模块文件拷至 wheel 根）。
wheel.packages 显式列出后需同时声明纯 Python 包 omigamax，否则自动发现被禁用。

新增文件:
  cpp/CMakeLists.txt      (cmake_minimum_required 3.15...3.27; find_package(pybind11 CONFIG REQUIRED); pybind11_add_module)
  cpp/omigamax_core.cpp   (PYBIND11_MODULE(omigamax_core, m){ m.doc()="omigamax C++ core"; })
  cpp/omigamax_core.pyi   (类型 stub，wheel.py-modules 等价声明)
.gitignore 追加: *.pyd *.obj *.exp *.lib CMakeCache.txt CMakeFiles/

依赖版本: [project] dependencies 原样未动（flask/numpy/pygame/pytest/pyyaml/torch==2.13.0+cu130），
