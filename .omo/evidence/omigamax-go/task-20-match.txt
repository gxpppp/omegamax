1. IMPLEMENTATION (design)
--------------------------------------------------------------------------
omigamax/cli/match.py
  - `match` CLI (default subcommand; `play` subcommand dispatches to
    omigamax.cli.play):
      omigamax.cli.match match --engine2 katago|random --model models/best.pt
                             --games N [--sims S] [--katago-visits V] ...
  - engine1 = omigamax IN-PROCESS (todo-18 GTPEngine, configurable sims,
    evaluation discipline: no Dirichlet root noise, tau=0 argmax).
  - engine2 = katago: GTP SUBPROCESS `katago gtp -model <weights> -config
    <cfg>` (tools/katago eigen CPU build; the plan's "GTP 管道互叫", CRLF-
    tolerant frames, per-command timeout -> kill, todo-18 pipe patterns);
    rule components reused from todo 5 (ko SIMPLE / AREA / tax NONE /
    suicide false) + optional `kata-set-param maxVisits N` cap.  engine2 =
    random: in-process uniform-random-legal engine (plan's vs-random
    milestone command, Oracle F4).
  - colour alternation: game index even -> engine1 black, odd -> engine1
    white; komi 7.5 (config) on white; seeds = master + game index.
  - a local Board arbitrates legality (genmove parsed via GTP coords
    A-T skip I; illegal/rejected move -> error record + engine stderr, not
    a crash). Two-pass terminal (Tromp-Taylor); --max-moves force-
    terminates and scores.
  - report: per-game results (seed, colour, winner, moves, result, SGF) +
    aggregate win rate of engine1 + ELO diff (400*log10(p/(1-p)), clamped
    to +-2400; reuses omigamax.train.evaluate.elo_from_winrate). All game
    SGFs -> logs/matches/.
omigamax/cli/play.py
  - `play` CLI: human-vs-engine terminal play. Text board (GTP orientation,
    columns A-T skip I, last move lower-case). Human reads GTP coords from
    stdin; illegal/invalid move rejected + re-prompted; `quit` exits. Engine
    replies via MCTS (--vs omigamax) or seeded random (--vs random).
    Two-pass terminal -> final score printed. play_session() is the reusable
    driver with an injectable engine (test seam).
