4. Implementation notes (findings)
------------------------------------------------------------------
a) Buffer design (omigamax/train/buffer.py): window of the newest
   replay_buffer_games=1000 npz games; AGZ sampling -- uniform over window
   games (with replacement), uniform recorded position within a game; z in
   (B,1); LRU cache capped at cache_limit games; window enforced on disk via
   selfplay.prune_old_games; no future-position leakage by construction.

b) lr schedule (omigamax/train/train.py agz_lr): AGZ piecewise with config
   lr_schedule_steps=[50000,100000] -> 0.2 for step<50000, 0.02 for
   50000<=step<100000, 0.002 for step>=100000 (AGZ 300K/500K scaled to batch
   128). lr(0)=0.2, lr(50000)=0.02, lr(100000)=0.002. Applied per step by
   setting the SGD param-group lr before each step.

c) 8-fold symmetry (omigamax/train/symmetry.py): D4 group = identity + 3
   rotations + 4 reflections. pi index convention: idx=r*N+c; pi_aug = pi[perm]
   with perm[flat(T(p))] = flat(p) and pass fixed; feature tensor transformed
   in the SAME frame (s_aug[:, T(p)] = s[:, p]) sharing the same flat dest map
   -- consistent by construction. Round-trip verified on a real network.

d) CUDA finding -- large-batch cuDNN pathology: conv forwards for batch >=512
   are pathologically slow on this 3060 build (batch-512 forward ~130s vs
   batch-128 ~0.2s; flaky first-call cost 68s to >10min). The 8-fold augmented
   batch (8 x batch_size = 1024) is therefore processed as chunks=8 of
   batch_size with gradient accumulation (equivalence validated in
   TestChunkedTraining); each forward/backward stays at the proven-fast 128.

e) CUDA finding -- momentum stability: at the locked lr=0.2/momentum=0.9 on
   FRESH buffer data (fresh batch each step, unlike the todo-8 fixed synthetic
   batch) the SGD dynamics diverge (weight norm 102 -> 1.5e9 in 55 steps; NaN
   within 100 steps). The plan's NaN remedy clip 5.0 prevents NaN but the loss
   still grows (7.56 -> ~80 over 200 steps). A tighter gradient-norm clip of
   1.0 stabilises the SAME locked lr/momentum (7.56 -> 3.04, ratio 0.40 over
   200 steps). grad_clip is a training-pipeline parameter (not a config/
   default.yaml key); DEFAULT_GRAD_CLIP=1.0 is evidence-backed here and the
   plan's 5.0 remains available via --grad-clip 5.0. This is recorded as a
   finding, not a config change.

f) Checkpoint format (omigamax/train/train.py): dict {format, version,
   global_step, arch, model_state_dict, optimizer_state_dict, config, rng_state}
   saved to models/latest.pt atomically (.tmp + os.replace). The numpy buffer
   sampling RNG state is persisted so deterministic-resume is EXACT
   (measured max|diff| = 0.0).
